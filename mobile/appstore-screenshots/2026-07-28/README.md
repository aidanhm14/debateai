## Read before using 03-live.png

It is a real screenshot of the real live-round UI, and the names on it
("Cleo I.", "Inez G.") are **privacy aliases** generated by
`app/js/public-identity.js`, which is how that surface always renders real
accounts. Nothing is mocked.

The caveat: the match completed within seconds of queueing on a simulator,
and a browser session of mine was sitting in the queue from earlier testing.
So the "opponent" was almost certainly my own second session, not a third
party. The UI is genuine; the *situation* was self-made.

That is fine by Apple, whose rule is that screenshots show the app in use.
It sits less comfortably against our own standard that preview matches must
never read as real current events. Using it advertises live human matching
as the everyday experience while the queue is usually empty. Aidan decides.

Safe alternative if you would rather not: ship 01 and 02, and capture a third
from the Live tab's searching state (the globe), which promises nothing.

## Recapture recipe

```bash
xcrun simctl boot 08421C33-7A7C-46F7-9FD0-B6F8EF8ACBAE   # iPhone 17 Pro Max
xcrun simctl install booted mobile/ios/App/build/Build/Products/Debug-iphonesimulator/App.app
xcrun simctl launch booted com.debateai.debateit
xcrun simctl io booted screenshot --type=png out.png      # lands at 1320x2868
```

Tab bar centres in points at this size: Home 44, Debate 132, Coach 220,
Live 308, Me 396, all at y 915.
